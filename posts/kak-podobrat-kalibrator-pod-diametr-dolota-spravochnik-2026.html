Классификатор калибраторов для бурения: принципы подбора под КНБК

Калибратор — наддолотный элемент КНБК, сохраняющий номинальный диаметр ствола, центрирующий долото и снижающий вибрации. Подбор строится на трёх осях: наружный диаметр калибратора, присоединительная резьба по ГОСТ 28487-90 и тип вооружения под категорию абразивности пород.

Генеральный классификатор решений

Практика бурения в Западной Сибири показывает: корректный подбор калибратора снижает риск срыва резьбы и преждевременного износа КНБК. Основные категории — прямолопастные, спиральнолопастные и шарошечные калибраторы. Выбор между ними определяется геологическим разрезом и типом долота.

Детальный рубрикатор направлений

Прямолопастные и спиральнолопастные: выбор по геологии

Прямолопастные калибраторы (КЛ) применяются при бурении в породах средней твёрдости и твёрдых, обеспечивая минимальное гидравлическое сопротивление. Спиральнолопастные (КЛС) предпочтительны в мягких и средних породах: спиральная геометрия улучшает стабильность инструмента, снижает вибрацию и износ.

Стандартный размерный ряд КЛН (сварных прямолопастных) охватывает диаметры от 269,9 до 610,4 мм с резьбами 3-152, 3-177 и 3-201 по ГОСТ 28487-90. Для диаметра 215,9 мм типичны КЛС и КЛВ с резьбой 3-147.

Шарошечные калибраторы: для абразивных пород

Шарошечные калибраторы типа КШУ применяются при бурении в абразивных породах и для расширения желобов. Конструкция со сменными калибрующими узлами позволяет восстанавливать номинальный диаметр при износе до 6 мм. Это критично для сохранения проходного сечения ствола при износе долота.

Технические характеристики КШУ: диаметры 393,7–555,0 мм, резьба 3-171, максимальная частота вращения 90–150 об/мин. Для тюменского региона такие позиции поставляются через локальные металлобазы, например, калибратор 188,9 мм шарошечный КШ ТК доступен в Тюмени.

Чек-лист подбора калибратора

  • Определите номинальный диаметр долота. Наружный диаметр калибратора должен соответствовать диаметру долота с допуском, исключающим заклинивание.
  • Проверьте тип резьбы по ГОСТ 28487-90. Для долот 215,9 мм стандарт — 3-147; для 295,3 мм — 3-171; для 393,7 мм — 3-171.
  • Оцените категорию абразивности пород. Для абразивных — шарошечные или с твердосплавным вооружением; для мягких — спиральнолопастные с алмазным вооружением.
  • Сверьте длину калиброванной части. Стандарт — 296–704 мм в зависимости от диаметра; для 215,9 мм типична длина 960–1100 мм.
  • Проверьте совместимость с КНБК. Калибратор устанавливается над долотом или над забойным двигателем; тип резьбы должен совпадать с переводником.
Отраслевой стандарт ОСТ 39-078-79 регламентирует типы, исполнения и вооружение калибраторов. Для тюменских условий характерно применение спиральнолопастных калибраторов при бурении под эксплуатационную колонну с PDC долотами.

Реальный регламент: ГОСТ 28487-90 и ОСТ 39-078-79

Присоединительные резьбы калибраторов нормируются ГОСТ 28487-90. Для диаметров 120,6–215,9 мм применяются резьбы 3-66–3-147; для 269,9–393,7 мм — 3-147–3-177; для 444,5–660,4 мм — 3-177–3-201. Шарошечные калибраторы КШУ по ОСТ 39-078-79 оснащаются резьбой 3-171 и сменными узлами с клиновым креплением.

FAQ по подбору калибратора

Можно ли ставить калибратор большего диаметра, чем долото?

Нет. Наружный диаметр калибратора не должен превышать диаметр долота — это приведёт к заклиниванию и повреждению ствола. Допускается соответствие номинальному диаметру долота с учётом износа.

Какая резьба нужна для долота 295,3 мм?

Стандартная присоединительная резьба для калибраторов под долото 295,3 мм — 3-171 по ГОСТ 28487-90. Для лёгких условий возможна 3-152, но это ограничивает нагрузочную способность.

Чем отличается КЛС от КЛН?

КЛС — калибратор лопастной спиральный; КЛН — прямолопастный сварной. КЛС эффективнее для стабилизации в мягких породах, КЛН — для снижения гидравлических сопротивлений в средних и твёрдых.
